# ADR 0006 — Both Adult Reference Bodies

- Date: 2026-10-11
- Status: accepted requirement; asset feasibility unverified.
- Deciders: user.

## Decision

Include male and female adult reference anatomy in the first-release plan.

## Consequences

Audit coverage and spatial support separately. Both bodies need the same published
core exploration tasks. Do not satisfy the requirement with an exterior-only swap.
Preserve corresponding navigation context where mappings exist.

Candidate sources do not yet establish full two-body coverage. Missing structures,
internal detail, and connections require explicit enrichment or a reviewed scope
revision before public release.
