# ADR 0002 — Application Licensing Remains Open

- Date: 2026-10-11
- Status: proposed / unresolved.
- Deciders: user decision needed before implementation distribution.

## Context

Free launch and potential paid features are established. Neither establishes an
open-source or proprietary application licence. There is no application code yet.

## Proposed handling

Keep application licensing explicitly undecided while planning. Evaluate the desired
contribution/reuse model before distributing implementation. Do not silently apply
MIT, AGPL, or another licence.

## Consequences

Engine notices and asset terms still apply independently. Future commercial plans
must be assessed against actual source licences. No licensing file is added by this ADR.
