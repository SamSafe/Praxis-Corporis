# ADR 0005 — Native Exploration with Continuous Context

- Date: 2026-10-11
- Status: accepted product direction.
- Deciders: user.

## Decision

Target Windows and macOS native desktop. Exploration is primary. Keep selected
anatomy inside the continuous body scene and support travel between structures.
Provide both manual disassembly and guided separated views.

The main reference journey moves from whole body to heart parts and conditions,
then follows connections toward the lungs. Clean detail leans realistic.

## Consequences

The earlier browser/quiz-centred proposal is superseded. Quizzes, mobile, VR,
animation, and microscopic detail are later work. Exact controls and engine remain
draft recommendations.
